# KWAK Portfolio

20년차 웹디자이너를 위한 반응형 포트폴리오. 별도의 패키지 설치 없이 실행합니다.

## 실행

`npm run dev` → http://127.0.0.1:5173

`npm run build` → 정적 배포용 dist 폴더 생성

## 콘텐츠 수정

- `index.html`: 소개, 경력, 프로젝트, 연락 링크
- `app.js`: 프로젝트 상세 내용 및 필터
- `style.css`: 반응형 스타일 및 CSS 콘셉트 그래픽

네 프로젝트는 실제 고객 작업이 아닌 콘셉트 예시입니다. 실제 작업 이미지, 프로젝트명, 역할과 결과로 교체하세요. 연락처가 제공되지 않아 현재 연락 링크는 GitHub 프로필을 사용합니다. Google Fonts를 불러오며 연결이 없으면 시스템 글꼴을 사용합니다.
